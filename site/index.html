The one rule

Tip the Can looks down on the street. Kerby looks along it from the pavement. A painting belongs here only if it reads from both.

    Using it in a game

    Each game keeps a copy in addons/street_kit/ and upgrades on purpose. From the game's repo:

    tools/update_street_kit.sh 0.2.0   # a specific version
tools/update_street_kit.sh         # the latest
godot --headless --import --path .

    Then check the game and commit addons/street_kit/, .import files included. Load files as res://addons/street_kit/….

    Read the changelog before upgrading.

    • Major An asset was removed, renamed or resized. Check the game first.
    • Minor New paintings. Safe.
    • Patch A repaint, same name and size. Safe.

    Need something new? Open an issue describing it and which games want it.
